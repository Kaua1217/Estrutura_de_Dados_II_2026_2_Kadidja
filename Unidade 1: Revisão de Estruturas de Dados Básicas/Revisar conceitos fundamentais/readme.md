# Revisar conceitos fundamentais

Esta pasta contém os materiais e a atividade referente à unidade de **Revisão de Estruturas de Dados Básicas** da disciplina de **Estrutura de Dados II**.

## 📚 Aula

O material apresentado nesta pasta corresponde à aula de revisão dos conceitos fundamentais de estruturas de dados.

* [Aula Inaugural - Estrutura de Dados II]

## 💻 Atividade

Como parte da atividade proposta, deve ser implementada uma estrutura de dados e o código deve ser disponibilizado no GitHub, realizando o processo de `commit` e `push`.

Entre as estruturas sugeridas estão:

* **Pilha**
* **Fila**
* **Quick Sort**

### Estrutura escolhida

Para esta atividade foi escolhida a implementação de uma **Pilha (Stack)**.

A implementação está disponível na pasta:

➡️ [Implementação de Pilha]

## 🎯 Objetivo

Revisar os conceitos fundamentais de estruturas de dados e aplicar esses conhecimentos por meio da implementação prática de uma estrutura de dados utilizando programação.

## 📌 Resultado

A atividade resulta em uma implementação funcional de uma **Pilha**, acompanhada de sua documentação e disponibilizada no repositório da disciplina.
